PHASE 2: CODE SMELLS DETECTION
================================

Code Smells Detected:
- God Object / Large Class: 1 instance (AppManager)
- Long Method: 2 instances (checkout handler, financial-report handler)
- Duplicated / Callback Hell: nested sqlite3 callbacks in checkout and report
- Feature Envy: route handlers access DB/config/crypto directly
- Shotgun Surgery: schema, seeds, HTTP, domain and payment mixed in one class
- Magic / insecure helpers: badCrypto, hard-coded secrets, global mutable state

Architecture Issues Detected:
- Lack of Separation of Concerns (no Model / View / Controller layers)
- Tight Coupling (AppManager owns DB, routes, business rules and payment)
- Global Mutable State (globalCache, totalRevenue in utils.js)
- Poor Error Handling and Logging (ignored errs, card/key logged)
- Missing transactions on multi-table checkout writes
- N+1 style queries in financial report
- Soft-delete integrity gap (DELETE users leaves orphan enrollments/payments)
- Hard-coded credentials and payment gateway key in source
