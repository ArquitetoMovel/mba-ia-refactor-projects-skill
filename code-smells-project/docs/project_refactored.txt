  RESIDUAL OPERATIONAL NOTES
  --------------------------
  - Sem `SECRET_KEY` em desenvolvimento, a chave é aleatória por processo; use
    uma variável estável ao executar múltiplos workers.
  - Usuários de seed não são criados sem `SEED_*_PASSWORD`; isso é intencional.
  - CORS fica desabilitado quando `CORS_ORIGINS` não é informado.
  - `app.run()` é somente o servidor de desenvolvimento; produção deve usar
    um servidor WSGI apropriado.
